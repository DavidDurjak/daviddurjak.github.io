Privacy Policy

YouTube Studio Tools. Last updated: 7 November 2026.

Who uses this tool

YouTube Studio Tools is a private tool used only by its operator to manage YouTube channels that the operator owns. It is not available to the public.

What data it accesses

When a channel owner signs in with Google and grants permission, the tool uses the YouTube Data API and YouTube Analytics API to access that channel's videos, playlists, captions, comments and analytics, and to upload and update videos on that channel.

How data is stored

Access tokens and the data the tool reads are stored only on the operator's own computer. Nothing is sold, shared with third parties or used for advertising.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Stored data is deleted from the operator's computer when access is revoked.

Contact

Questions can be sent to the support email shown on the Google sign-in consent screen for this app.
